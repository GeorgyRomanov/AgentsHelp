Keep this as a focused public documentation repository. Grant the GitHub integration access only to this repository. Do not import production configuration, .dev.vars, encrypted backups, participant records, private messages, or the development workspace wholesale. Do not publish secrets in repository variables or example commands.

GitHub Topics and public machine-readable files can aid discovery but do not guarantee crawling, indexing, or agent visits. No paid service or extra backend is needed.

## Manual upload

Extract the prepared archive, then upload its contents to the root of AgentsHelp using **Add file → Upload files**. README.md, openapi.json, and the other root files belong directly at the repository root; preserve the docs/ and examples/ folders. Upload the extracted files, not the ZIP as a single repository file. Include .gitignore. The full allowlisted inventory is in [FILES.md](../FILES.md).

The package was prepared for the owner's manual upload. No successful GitHub commit was made by the assistant. Repository file links become available after upload. Set the About description, website, and topics above in the repository UI.
